# Python Parking Management System

A simple terminal-based parking management system developed using Python.

## Features

- Vehicle entry (Motorcycle and Car)
- Automatic parking entry time
- Automatic parking exit time
- Parking duration calculation
- Automatic hourly billing
- Parking fee calculation
- 10% discount for parking longer than 4 hours
- Vehicle validation
- Parking ticket generation

## Technologies Used

- Python 3
- Datetime Module

## Parking Rates

| Vehicle Type | Parking Fee |
|---|---:|
| Motorcycle | Rp2,000 / hour |
| Car | Rp5,000 / hour |

**Discount:** 10% for parking longer than 4 hours.

## How to Run

Make sure Python is installed on your computer.

Run the following command in your terminal:

```bash
python parking_system.py
```
